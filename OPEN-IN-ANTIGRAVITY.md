# Open the complete portfolio

Extract this ZIP. In Antigravity or VS Code, open the Jwalith-Portfolio folder.

Run `python -m http.server 8000 --directory dist` from that folder, then open http://localhost:8000. No package installation or build step is required.

The final source cleanup is already merged. See README.md for the source map and personal GitHub deployment setup. FINAL-AUDIT.md records the earlier source audit and its limitations; it is not a claim of a new deployment.
